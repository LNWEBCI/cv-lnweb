## 🚀 Comment Lancer et Utiliser le Site

1. **Lancement direct en local** :
   - Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur moderne (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
   - Aucune dépendance lourde ni installation Node.js n'est requise.

2. **Pour recevoir les devis** :
   - Lorsqu'un visiteur remplit le formulaire de devis, le bouton **"Envoyer par Email à Maurel"** ouvre automatiquement son logiciel de messagerie avec toutes les informations structurées et pré-adressées à `serviceslnweb@gmail.com`.

3. **Pour exporter le CV en PDF** :
   - Cliquez sur **"Télécharger PDF"** dans le menu ou le Hero.
   - Dans la fenêtre d'impression, choisissez **"Enregistrer au format PDF"** (format A4).
